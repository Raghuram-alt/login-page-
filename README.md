# CAPITAL — Enterprise Revenue Intelligence Portal

A modern, cinematic Bitcoin-themed enterprise login portal.

## Features
- **Cinematic Bitcoin Intro Transition**: 3D Bitcoin vault entry animation with radiant aperture flash.
- **Interactive 3D Side Bitcoin Coin**: Real-time cursor motion tracking (tilt & drift), dynamic lighting sheen, and double-click / double-tap 360° flip animation with gold particle bursts.
- **Enterprise Authentication UI**:
  - Live email validation with strict domain requirement (e.g. `user@gmail.com`).
  - Password visibility toggle with accessible state tracking.
  - Remember me checkbox and security credentials badges.
  - Replay Intro button and Demo Auto-fill.
  - Fully responsive layout for desktop, tablet, and mobile.
- **Vanilla Web Stack**: Pure HTML5, CSS3, and JavaScript with zero external frameworks.

## Quick Start

Start the local server:

```bash
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
